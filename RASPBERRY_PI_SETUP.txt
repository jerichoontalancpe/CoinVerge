================================================================================
COINVERGE — RASPBERRY PI DEPLOYMENT TUTORIAL
Complete step-by-step guide to deploy CoinVerge on Raspberry Pi + 7" Touchscreen
================================================================================

WHAT YOU NEED:
- Raspberry Pi 4 (2GB or 4GB)
- Official 7" Raspberry Pi Touchscreen (800x480)
- 32GB microSD card (Class 10 or A1)
- 5V 3A USB-C power supply (for RPi)
- USB-A to Micro-USB cable (RPi to ESP32)
- A computer with SD card reader (to flash the OS)
- WiFi connection (for initial setup only)
- Keyboard + mouse (for initial setup only, can remove later)


================================================================================
PART 1: PREPARE THE MICROSD CARD
================================================================================

On your laptop (Mac or Windows):

STEP 1: Download Raspberry Pi Imager
    - Go to: https://www.raspberrypi.com/software/
    - Download and install "Raspberry Pi Imager"

STEP 2: Flash the operating system
    - Insert your 32GB microSD card into your laptop
    - Open Raspberry Pi Imager
    - Click "CHOOSE OS"
        → Select "Raspberry Pi OS (32-bit)" (the one with Desktop)
    - Click "CHOOSE STORAGE"
        → Select your microSD card
    - Click the GEAR icon (settings) before writing:
        → Enable SSH: YES
        → Set username: pi
        → Set password: coinverge
        → Configure WiFi: enter your WiFi name and password
        → Set locale: Asia/Manila, keyboard US
    - Click "WRITE"
    - Wait for it to finish (5-10 minutes)
    - Remove the microSD card


================================================================================
PART 2: CONNECT THE 7" TOUCHSCREEN TO RASPBERRY PI
================================================================================

STEP 1: Unbox the touchscreen
    - The official 7" RPi touchscreen comes with:
        - The LCD panel with a driver board on the back
        - A ribbon cable (flat, wide)
        - Jumper wires (red and black)
        - Standoffs/screws

STEP 2: Connect the ribbon cable
    - On the BACK of the touchscreen, find the "DISPLAY" connector
    - On the Raspberry Pi, find the "DISPLAY" connector (labeled DSI)
    - Insert the ribbon cable:
        - Lift the black clip on the connector
        - Slide the ribbon cable in (silver contacts facing the board)
        - Push the black clip back down to lock it

STEP 3: Connect power to the touchscreen
    - The touchscreen needs 5V power from the Raspberry Pi
    - Use the jumper wires:
        - RED wire: Connect from touchscreen "5V" pin → RPi GPIO pin 2 (5V)
        - BLACK wire: Connect from touchscreen "GND" pin → RPi GPIO pin 6 (GND)
    - Some screens use the USB port instead — check your specific model

STEP 4: Mount the Raspberry Pi
    - Use the standoffs to mount the RPi on the back of the touchscreen
    - The RPi sits flat against the back of the screen

STEP 5: Insert the microSD card
    - Insert the prepared microSD card into the RPi's card slot
    - The slot is on the underside of the Raspberry Pi board


================================================================================
PART 3: FIRST BOOT AND SETUP
================================================================================

STEP 1: Connect peripherals
    - Plug in a USB keyboard and mouse to the RPi
    - Plug the 5V 3A USB-C power supply into the RPi
    - The screen should light up and show the Raspberry Pi logo

STEP 2: Wait for first boot
    - It will take 1-3 minutes on first boot
    - It will expand the filesystem and reboot once
    - Eventually you'll see the Raspberry Pi desktop

STEP 3: Connect to WiFi (if not already configured)
    - Click the WiFi icon in the top-right corner
    - Select your WiFi network
    - Enter the password

STEP 4: Open Terminal
    - Click the Terminal icon in the top menu bar (black rectangle icon)
    - Or press Ctrl+Alt+T

STEP 5: Update the system
    Type these commands one by one (press Enter after each):

    sudo apt update
    sudo apt upgrade -y

    (This takes 5-15 minutes — wait for it to finish)

STEP 6: Install required software
    Type these commands one by one:

    sudo apt install -y git python3-pip python3-flask chromium-browser
    pip3 install flask pyserial

STEP 7: Fix the screen rotation (if upside down)
    If the touchscreen appears upside down:

    sudo nano /boot/config.txt

    Add this line at the bottom:
    lcd_rotate=2

    Press Ctrl+X, then Y, then Enter to save.
    Then reboot:
    sudo reboot


================================================================================
PART 4: INSTALL COINVERGE
================================================================================

STEP 1: Clone the project
    Open Terminal and type:

    cd ~
    git clone https://github.com/jerichoontalancpe/CoinVerge.git

STEP 2: Test it works
    cd ~/CoinVerge/CoinvergeUI
    python3 app.py --simulate

    Open Chromium browser on the RPi, go to:
    http://localhost:8080

    You should see the CoinVerge kiosk screen.
    Press Ctrl+C in Terminal to stop.


================================================================================
PART 5: CONNECT THE ESP32
================================================================================

STEP 1: Plug in ESP32
    - Use the USB-A to Micro-USB cable
    - Plug USB-A side into any USB port on the Raspberry Pi
    - Plug Micro-USB side into the ESP32

STEP 2: Find the serial port
    Type in Terminal:

    ls /dev/ttyUSB*

    It should show something like: /dev/ttyUSB0
    If nothing shows, try:
    ls /dev/ttyACM*

    Remember this port name (usually /dev/ttyUSB0)

STEP 3: Give permission to access the port
    sudo chmod 666 /dev/ttyUSB0
    sudo usermod -a -G dialout pi

STEP 4: Test with ESP32 connected
    cd ~/CoinVerge/CoinvergeUI
    python3 app.py --port /dev/ttyUSB0

    Open Chromium → http://localhost:8080
    Insert a bill — the screen should react!
    Press Ctrl+C to stop.


================================================================================
PART 6: SET UP AUTO-START (KIOSK MODE)
================================================================================

This makes CoinVerge start automatically when the RPi boots.
No desktop, no browser controls — just the CoinVerge screen.

STEP 1: Make the kiosk script executable
    chmod +x ~/CoinVerge/CoinvergeUI/kiosk.sh

STEP 2: Edit the kiosk script to use correct port
    nano ~/CoinVerge/CoinvergeUI/kiosk.sh

    Find this line:
    python3 app.py --port /dev/ttyUSB0 --web-port 8080 &

    Make sure /dev/ttyUSB0 matches your actual port from Part 5 Step 2.
    Press Ctrl+X, Y, Enter to save.

STEP 3: Install the systemd service
    sudo cp ~/CoinVerge/CoinvergeUI/coinverge-kiosk.service /etc/systemd/system/
    sudo systemctl daemon-reload
    sudo systemctl enable coinverge-kiosk

STEP 4: Disable screen blanking (prevent screen from turning off)
    sudo nano /etc/xdg/lxsession/LXDE-pi/autostart

    Add these lines at the bottom:
    @xset s off
    @xset -dpms
    @xset s nofill

    Press Ctrl+X, Y, Enter to save.

STEP 5: Hide the mouse cursor
    sudo apt install -y unclutter

STEP 6: Reboot
    sudo reboot

STEP 7: Verify
    After reboot, the screen should show:
    - CoinVerge logo
    - "Insert bill or coins below"
    - No desktop, no browser bar, no mouse cursor
    - Just the kiosk screen — ready for customers!


================================================================================
PART 7: ADMIN ACCESS (after deployment)
================================================================================

The admin panel is NOT visible to regular users (no address bar).
To access admin, there are two ways:

METHOD 1: From the kiosk screen
    - Tap the top-right corner of the idle screen 5 times quickly
    - This opens the admin panel

METHOD 2: From another device on the same WiFi
    - Find the RPi's IP address:
        Open Terminal (connect keyboard) and type: hostname -I
        It will show something like: 192.168.1.105
    - On your phone/laptop browser, go to:
        http://192.168.1.105:8080/admin
    - PIN: 1234 (or whatever you changed it to)


================================================================================
PART 8: UPDATING THE SOFTWARE
================================================================================

When we make code changes and push to GitHub:

STEP 1: Connect a keyboard to the RPi (or SSH in)

STEP 2: Stop the kiosk service
    sudo systemctl stop coinverge-kiosk

STEP 3: Pull the latest code
    cd ~/CoinVerge
    git pull

STEP 4: Restart the kiosk service
    sudo systemctl start coinverge-kiosk

Or just reboot:
    sudo reboot


================================================================================
PART 9: TROUBLESHOOTING
================================================================================

PROBLEM: Screen is black after boot
    - Check power supply (must be 5V 3A — weak supply = no boot)
    - Check ribbon cable connection (both ends firmly seated)
    - Check microSD card is properly inserted

PROBLEM: Screen shows desktop instead of kiosk
    - The service didn't start. Check:
        sudo systemctl status coinverge-kiosk
    - If it says "failed", check the log:
        journalctl -u coinverge-kiosk -n 50

PROBLEM: Kiosk shows but ESP32 not responding
    - Check USB cable is connected
    - Check port: ls /dev/ttyUSB* or ls /dev/ttyACM*
    - Check permission: sudo chmod 666 /dev/ttyUSB0
    - Check kiosk.sh has correct port name

PROBLEM: Touch not working
    - Try rebooting: sudo reboot
    - Check ribbon cable connection
    - Some screens need drivers: sudo apt install -y xserver-xorg-input-evdev

PROBLEM: Screen is upside down
    - Edit /boot/config.txt, add: lcd_rotate=2
    - Reboot

PROBLEM: Want to exit kiosk mode temporarily
    - Connect a keyboard
    - Press Ctrl+Alt+F2 (switches to text console)
    - Login: pi / coinverge
    - Stop service: sudo systemctl stop coinverge-kiosk
    - Press Ctrl+Alt+F7 to go back to graphical mode

PROBLEM: WiFi not connecting
    - CoinVerge does NOT need internet to work
    - WiFi is only needed for: phone e-payment demo, admin remote access
    - The system works fully offline

PART 10: PHONE E-PAYMENT DEMO (optional WiFi setup)
================================================================================

If you want to demo the phone e-payment feature:

OPTION A: RPi connects to existing WiFi
    - Both phone and RPi on same WiFi network
    - Find RPi IP: hostname -I
    - Phone opens: http://<RPi-IP>:8080/phone

OPTION B: RPi creates its own WiFi hotspot (no router needed)
    
    sudo apt install -y hostapd dnsmasq

    (This is more complex — we can set this up together when needed)
